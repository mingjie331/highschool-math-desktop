# 第三方组件

应用使用 Electron（MIT）、Chromium（多种许可）、React（MIT）、PDF.js（Apache-2.0）、FastAPI（MIT）、Uvicorn（BSD-3-Clause）、SQLite（公有领域）、CPython（PSF）、PyInstaller（GPL with distribution exception）、Lucide（ISC）、Pillow（HPND）、pypdf（BSD-3-Clause）、pypdfium2（Apache-2.0 / BSD-3-Clause，含 PDFium 及其依赖许可）、HTTPX（BSD-3-Clause）。开发测试使用 Playwright（Apache-2.0），不进入应用运行包。AI 功能调用用户配置的 DeepSeek 官方远程 API，模型本身不随程序分发。

Electron 附带的 `LICENSE`、`LICENSES.chromium.html` 和后端运行库文件均随应用保留。Python 及前端库许可位于 `resources/payload/resources/licenses`。具体构建版本见源码根目录与 frontend 的 package-lock.json，以及 requirements-build.txt。

未附带 TeX Live、MiKTeX 或系统中文字体。运行时使用目标电脑已安装的 LaTeX 环境。
