# 使用说明 · 1.3.4

## 启动与数据位置

开发者从克隆项目执行 `npm start`；发行包用户从自己的应用目录运行“高中数学题库.exe”，也可使用自行创建的快捷方式。设置显示实际程序版本、程序目录、数据目录；不要根据目录名称判断版本。

固定目录下 `data` 保存题库、来源、草稿、配图、图片/PDF原材料和加密密钥；`.cache/electron` 含解密上下文，`.cache/source-preferences` 保存题源偏好；`output` 保存成功导出，`logs` 保存日志。保留这四个目录。密钥迁移到其他电脑或账户可能需要重新填写。

## 录题与核对

AI录题分为录题任务、待核对、待入库。支持PNG/JPEG/PDF，单批20物理页/50题，图片12MiB、PDF32MiB且无需密码。单文件题源显示文件名，多文件各题采用题干文件来源；手动修改后整批统一，偏好可重启恢复。

指定题号可填19、1,3,19或17–19；跨文件试卷答案需配对并选择双方页面。同一PDF含试卷答案时不配对。裁剪限制实际识别范围。

有效题干才进入待核对；失败项留在任务中重试。按题干、配图、答案解析、分类题源和排版检查清单处理提示，一次人工确认整题后进入待入库。原材料可滚动、缩放、拖动；裁图后确认完整性。编译通过不表示数学正确，正式入库仍待核验。

删除候选题会删除该题草稿，保留原材料、其他候选和正式题库。切题和退出会保存草稿，保存失败请处理提示后再退出。

## 预览、组卷及导出

运行需已安装XeLaTeX及中文字体和宏包。设置可选择xelatex.exe并测试编译。各集合双册采用同一题库快照，训练卷保留自选顺序和配图；旧成功版本保留在output。解答题小问独立分段，旧排版规则导出需重新生成。

## 本地更新

将新发行Windows ZIP、对应校验清单和release.json放在同一目录。双击固定目录“本地更新.cmd”，选择ZIP。工具校验、正常退出、备份程序、更新并核验；失败恢复旧程序。完成后启动，在设置核对版本和数据位置。重复更新相同内容返回已是此版本；不支持普通流程降级。

更新仅替换程序文件，不合并数据库，不覆盖data/.cache/output/logs。无需Python、Node.js，不新增联网更新服务。
