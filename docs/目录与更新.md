# 目录与更新 · 1.4.0

## 开发目录与日常安装

开发项目位置由克隆时选择，执行 `npm start` 后使用项目的 `runtime`。正式 Windows 发行包解压到有写入权限的自选应用目录，从该目录中的“高中数学题库.exe”启动。应用设置显示实际版本、程序目录与数据目录。

在运行根目录下，`data` 保存数据库、草稿、组卷、配图、原材料及加密密钥；`.cache/electron` 含解密上下文，`.cache/source-preferences` 保存题源偏好；`output` 保存导出，`logs` 保存日志。这四个目录需要保留，不能整体清理或提交到 GitHub。换电脑使用自己的 API 密钥。

## 源码与本机资料

`backend/frontend/desktop/resources/scripts/tests` 为源码和资源，`docs` 为公开说明。`.venv`、依赖目录、PDF.js 生成资源、`build` 都可按清单重新生成。

`.local/test-materials` 为私有材料，`.local/backups` 为完整恢复资料；`test-results` 是隔离测试输出，可能含材料、数据库和加密配置。原始 `docs/validation` 保留在维护者本机，公开仓库仅提供 [验证摘要](公开交接验证.md)。这些目录均不进入公开提交或源码 ZIP，不因本次公开而清理。

未知缓存必须先确认用途。Electron 配置、加密上下文和题源偏好不能当作普通临时文件删除。

## 构建与更新

`build` 保存可重建暂存产物；`release/<版本>` 保存发行 ZIP、校验清单、发行说明和 `release.json`，同版本发行不能覆盖。公开 Git 仓库保存源码，不提交这些 ZIP 或旧程序副本。

更新时将新 Windows ZIP、对应 `checksums` 清单和 `release.json` 放在一起，双击发行包中的“本地更新.cmd”选择 ZIP。工具验证文件清单、请求正常退出、备份并更新程序；失败恢复旧程序。保存失败或退出超时会停止更新，不会强制结束程序。

更新后在设置核对版本和数据目录。更新仅管理程序文件，不合并数据库，不覆盖 `data/.cache/output/logs`；陌生文件保留。相同包可重复执行，同版本不同内容和普通降级均拒绝。

从 1.3.4 首次升级到 1.4.0 时，使用新版源码的 `scripts/update_app.ps1`，或先从新版 Windows 包解压取得 `tools/update_app.ps1`，显式指定旧应用目录和外部备份目录。旧版更新工具仅接受 schema 8，会拒绝 schema 9 新包；新版工具支持 8/9 并核对发行清单。程序首次启动迁移数据库前要保留完整旧安装及数据库备份，回退时恢复二者。

命令行更新和初次安装迁移需显式传入你自己的应用目录与外部备份目录，参见各脚本帮助。已有日常题库不得作为实验数据，恢复时应使用已核验的完整备份。


## 1.4.0 多题库更新

题库名称可自定义，系统题库保留所有旧内容；新题库初始为空，复用学期/专题/考点框架。题目、草稿、AI 会话、组卷和导出按题库隔离。批量移动和复制由题库管理操作，移动需先处理编辑草稿。单个 PDF 可导入 35 页，每批仍最多识别 20 页，选择或取消不会删除材料。数据库 schema 9，回退需配套恢复迁移前数据库和旧程序。
