# 1.4.1 界面修复验证

验证日期：2026-10-08。数据库仍为 schema 9，题目和 API 配置不作迁移。所有自动交互验收使用隔离数据，不调用付费 AI 服务。

## 原因与修复

原阅读区用固定窗口高度减去常数，并设 520 像素最小高度；工具栏换行及浏览器缩放后，阅读区底部会超出真实窗口。旧测试只比较最后一个源码卡片与容器的边界，没有检查窗口边界。现在主窗口由工具栏实际高度与剩余工作区构成，阅读区伸缩，源码、题目树和导出区分别滚动。

题库和学期在左侧顶部以两行紧凑下拉控件呈现，控制区不超过侧栏三分之一。弹窗采用固定顶部关闭栏和滚动正文，已有保存与关闭流程保留。

## 验收结果

- 主窗口：1450×940、1250×680、1000×680，分别在 100%、125%、150% 缩放下验收，共九组组合；等待实际尺寸生效后，核对源码最后文字、阅读区与窗口的边界。
- 操作：真实滚轮、键盘及滚动条拖动均能到达末尾，主文档没有被迫滚动；专题题目树独立滚动，顶部选择区保持可见。
- 弹窗：题库管理、设置、草稿箱、组卷、导出、编辑器、粘贴识别，以及 AI 裁剪、合并、删除确认、原 PDF 和待入库预览的顶部关闭入口可实际点击；保存失败时编辑器保持打开。
- 源码与 Windows 包分别通过六组专项场景；打包版使用原生窗口捕获保存截图，避免隐藏窗口的浏览器截图超时影响验收。
- 普通回归：159 项后端、14 项前端逻辑、4 项密钥与偏好存储测试通过。
- 原有行为：11 项桌面、11 项模拟 AI 工作台、5 组多题库与 PDF 选择场景通过。
- 种子库原始字节、627 道题和 87 张配图保持不变；个人数据、原始测试材料与输出继续排除公开提交。

日常安装已更新至 1.4.1，启动显示系统题库 628 道题、4 份草稿。包含元数据在内的原有 20 张表逐项核对一致，schema 保持 9，完整性和外键检查通过。密钥文件原字节及系统加密上下文保留，配置可正常读取，所有程序文件匹配发行清单。
